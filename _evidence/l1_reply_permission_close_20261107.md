1. **认可“规格可自动答，价格转人工”，公开原文保留价格。**  
   这是“自动答复不作价格承诺”的边界，公开证据中的价格仍可见。本轮不要求字段级证据裁剪；验收和对外说明应准确写成“客户目录答复不含价格”，避免承诺“客户不可见价格”。

2. **认可培训问答限定当前任务课程源。**  
   任务内问答以本课程为依据，边界合理。跨课程综合问答应另行定义授权范围，本轮不扩至同岗位课程。必须坚持：白名单为空时拒答，不能退回全库召回；引用白名单也不能替代召回阶段的限制。

3. **认可导师按班组或岗位授权，多目标用多行。**  
   本轮无需部门级授权。一条记录必须且只能指定一个目标；授权匹配必须包含租户边界，并独立拒绝本人签核本人任务。统一返回 403 合理。SQL 维护台账可作为当前运维方式，写入权限应限于可信管理身份。

4. **接受请求级 session GUC，但要求收进统一连接工厂。**  
   租户上下文的正确性应由统一入口保证，不能依赖每个调用者记得绑定、清除。业务代码直接从 pool 取连接应被禁止。放行条件是：
   
   - 每次借出连接，在业务 SQL 前绑定可信租户；
   - 正常、异常、取消路径均执行清理；
   - 清理结果不会被后续 rollback 撤销；
   - 清理失败时丢弃连接，不能归还池中复用。

   这里是对高风险生命周期的门禁要求，并非认定现实现已发生串租户。
