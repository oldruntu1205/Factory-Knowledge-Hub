# 设计稿：答案—证据一致性检查（确定性，不引入模型）

- 日期：2026-11-06
- 提出方：L2 实施
- 风险归类命中：**问答语义/可信边界变化**（新增一道拦截）
- 请只做判断：**不要探索仓库、不要读源码、不要跑测试**。

## 1. 要解决的问题（实测）

`tax-04`：问"产品目录里的价格含税吗？"，语料里**税费信息 0 处**，模型仍答「价格不含税」，
系统给了 `ANSWERED`。同类风险：模型把「14-70mm」答成「24*24」（`spec-02`，已被禁止串用例抓到，
但那是测试集的运气，不是系统的能力）。

现在的引用清单只证明"模型说它用了哪些证据"，**不证明答案内容真的来自证据**。

## 2. 拟议做法：确定性断言，不引入模型

只检查**可机械核验**的两类内容（不含语义判断）：

1. **货号**：答案里出现的 `[A-Z]{1,3}\d{5,8}`，必须逐字出现在该答案**引用的证据块**里；
2. **数字 + 单位/量词**：答案里 `\d+(\.\d+)?` 紧跟 `mm|cm|ml|l|g|kg|%|℃|元|只/箱|mm×mm` 等量纲的片段，
   其数字部分必须出现在引用证据里（纯序号、列表编号、"以下三点"这类不算）。

判定：

- 提取答案的 claim 集合 → 与「引用证据块正文」逐条比对（子串匹配，数字先规范化：去空格、统一全角）；
- 若**任一货号**不被支持 → 记 `UNSUPPORTED_CODE`；
- 若**数字类 claim 支持率 < 100%** → 记 `UNSUPPORTED_NUMBER`（阈值待你定，我倾向"有任何一个不支持就标记"，
  因为价格/规格错一个就是错）。

## 3. 命中之后怎么处理（要你定）

三个候选：

- **A. 降级为 `HUMAN_REVIEW_REQUIRED`**：答案照给（带引用），但标记需人工复核。与现有"伪造 ID"处理一致。
- **B. 降级为 `REFUSED`**：不给答案，只说明"无法确认"。
- **C. 只记审计/日志**，状态不变。

我倾向 **A**：不一致≠一定错（模型可能改写措辞、单位换算），但也不能当作可信答案直接放行。
B 的风险是把"其实对、只是换了说法"的答案也拒掉；C 则等于没有拦截。

## 4. 待判问题

1. 选 A / B / C？（我推荐 A）
2. 比对范围：只跟**引用证据块**比，还是跟**本次全部证据块**比？
   我倾向"引用证据块优先，模型没给引用时退回全部证据"——引用是它自己声明的依据。
3. 数字 claim 的提取边界：`14-70mm` 这种**区间**怎么算？（我打算拆成 14 与 70 两个数字分别要求出现）
   单位白名单要不要固定成一份常量表（避免"第 3 页"这类被误判）？
4. 命中后是否要把"未被支持的 claim 列表"返回给调用方？（可能泄漏证据细节，还是只返回数量？）
5. 复用现有拒答码（`INSUFFICIENT_EVIDENCE`）还是**新增拒答码**（如 `UNSUPPORTED_CLAIM`）？
   新增要动 `error.json` 契约 + 审计枚举。
6. 要不要给"支持率"留一个可观测指标（审计字段）？还是只写日志？

## 5. 实施侧要补的断言（供裁剪）

1. 货号不在引用证据里 → 按裁决标记；
2. 正确货号 + 正确价格 → 正常 `ANSWERED`；
3. 区间数字（14-70mm）拆开逐个校验；
4. 纯列表编号（"以下三点""1."）不触发；
5. 单位白名单外的数字（"第 3 页"）不触发；
6. 无引用（`引用：无`）时行为与既有规则一致（`INSUFFICIENT_EVIDENCE`）；
7. 性能：单次检查的耗时上限（答案 + 5 块证据，预期 <5ms）；
8. 回归：`tax-04` 这类"证据里根本没有"的答案必须不再 `ANSWERED`。
