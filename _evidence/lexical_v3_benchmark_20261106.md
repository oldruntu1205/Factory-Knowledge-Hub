## 1. 改了什么

候选集**不变**（字级 OR + GIN），只换排序：

```
score(d, q) = Σ_t idf(t) · tf·(k1+1) / (tf + k1·(1 - b + b·|d|/avg_len))
idf(t) = ln((N - df + 0.5)/(df + 0.5) + 1)
k1 = 1.2, b = 0.75（固定，不做配置）
```

- `N / df / avg_len` 取自**同一可见性范围的全部块**（租户 + scope + 状态 + ACL），
  按 ACL 分组后在 Python 侧求值；不可见块不参与统计（有专门用例）。
- 候选窗口上限 `MAX_CANDIDATES = 200`；`max_results > 200` 显式拒绝；
  `SearchOutcome` 增加 `window/truncated` 诊断字段。
- 一次 SQL 往返完成统计（UNION ALL 汇总 + 逐词 df），per-term 统计用 `plainto_tsquery`
  兼容运算符输入。
