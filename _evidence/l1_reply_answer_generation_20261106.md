**裁决：有条件通过本切片，可进入实施；无需等待 ADR-04 签署。** 本判断仅依据送审材料，未探索仓库、读取源码或运行测试。下列条件纳入实现后终审。

1. **ADR-04 未签期：允许显式启用本地 Ollama。**  
   按你提供的 README 约束，本地推理属于允许路径。保留默认 `none`，禁止外部回退。仅检查 URL 字符串不足：必须限制实际连接目标为 loopback，禁止跟随重定向、绕经环境代理，并确保所选模型确实在本机离线执行。`localhost` 必须解析到 loopback；不得自动拉取模型或转调云端。

2. **生成故障：503 + 审计 `ERROR`，不转为 `REFUSED`。**  
   超时、连接失败、模型不可用和生成协议解析失败均属能力故障；知识不足才走拒答判定。`ERROR` 是审计状态，**不得塞进**只允许三种业务状态的 `answer_response`。503 使用明确的错误响应契约，携带 `trace_id`，不得暴露内部地址、提示词或异常原文。超时、模型不存在等故障原因可分别记录，但本切片不强制细分 HTTP 状态。

3. **不强制 JSON；允许采用 `[evidence_id]`，但须固定提取协议。**  
   JSON 能改善解析，不能证明答案有据。无论哪种格式，都必须只解析最终答案，排除思考内容；检查答案非空、引用标记完整，并将所有候选 ID 交给现有白名单校验。格式无法可靠解析时不得继续作答。  
   **修正验收前提：“全部 ID 合法”只是 `ANSWERED` 的必要条件。** 还须检查每个实质性结论都有引用；合法引用仍不能证明结论受到证据支持。仅有未覆盖结论时按现有零有效支持路径拒答并要求人工复核；与部分伪造同时出现时，保留现有 `HUMAN_REVIEW_REQUIRED` 判定。不要用结构化输出替代这条边界。

4. **提示注入：三层措施可作为本切片基线，但不足以单独保证答案可信。**  
   不要求启发式注入检测，也不要求凭“疑似注入”关键词自动转人工。必须同时保证：证据不能改变系统指令或消息角色；生成器没有工具、文件或其他数据访问能力；上下文仅包含本次授权内容；引用核验覆盖最终展示内容。父块恢复同样不得绕过 ACL。  
   无法满足引用覆盖、输出协议等可检查条件时，拒答或转人工；不能把模型自称“未受注入影响”作为通过依据。`HUMAN_REVIEW_REQUIRED` 内容须明确呈现为待复核结果，不能作为正常答案使用。

5. **审计：本切片不强制新增列，但模型必须可追溯。**  
   `model_id` 不能只依赖可变的 `qwen3:14b` 标签；应能通过现有字段或关联的部署记录定位实际模型 digest／不可变版本。生成耗时、提示模板版本、运行参数可先进入受控遥测，无需为此扩表。  
   明文禁存应覆盖日志、异常、链路追踪中的 query，以及可能复述 query 的提示词和输出，不能只约束数据库。HMAC 密钥不得落库或日志。**授权请求进入答案服务后，配置缺失也记一条 `ERROR`。** 审计写入失败时不得返回成功；不能声称已经记录了实际未写入的 `ERROR`。

6. **模型：必须显式配置，不提供默认 `qwen3:14b`。**  
   provider 为 `none`、模型名为空或配置不合法，都不得启用生成。非法地址在配置加载／生成器构造阶段拒绝；运行时请求遇到能力未就绪返回 503。部署配置须绑定实际获准使用的本地模型。

7. **语言：作为有效请求参数执行，不能只记录。**  
   `zh-CN/en` 应进入生成指令，正文按请求语言输出；引用 ID、定位信息和必要原文术语保持原样。不支持的语言按既有请求校验规则返回 4xx。不要仅凭简单语言识别启发式，把技术术语或混合语言证据误判为生成故障。

对 §4 的断言，**保留十项，不删减，作以下修订／补充**：

- **第 1、6 项明确优先级：**先完成认证、授权及请求校验，再检查生成配置；配置完整时检索无证据才返回 `NO_EVIDENCE`，且不调用生成。配置缺失返回 503，并记录 `ERROR`。越权请求始终不能被配置错误掩盖。
- **第 2 项收紧：**有效引用、非空答案及结论引用覆盖均满足，才可进入 `ANSWERED`；增加“合法 ID 但有未引用结论”的反例。该检查不等于已经验证语义支持。
- **第 3、4 项保留：**沿用现有拒答与部分伪造判定，不静默删除伪造引用后宣告成功。
- **第 5 项补充：**覆盖最终答案解析失败；验证 503 错误契约，且审计状态不会泄漏为业务响应状态。
- **第 7 项补充：**验证重定向、代理和 `localhost` 解析不会造成非本地连接；确保无外部回退。
- **第 8 项补充：**问答主记录与引用记录原子写入；失败不留半套引用。将“恰好一条”限定为一次服务端请求执行，客户端重试是否去重另属幂等契约。
- **第 9 项补充：**覆盖父块恢复，证明其不会把越权内容重新带入上下文。
- **第 10 项补充：**分别验证三种业务响应与 503 错误响应；增加语言参数行为验证。

`/v1/training/ask` 继续留在本切片之外。实现后终审重点是本地连接边界、引用覆盖与状态判定、审计失败处理这三处。
