## 1. 下一步顺序（三条并行主线 + 两项工程闸门）

### A. 新人培训链路（Rev2 §13，需端到端验收）

端到端顺序（每一步都要有断言）：

1. **分配课程**（岗位/入职批次）→ 学员用自己的令牌能查到自己的任务，**看不到别人的**；
2. **阅读批准内容**：只能读 `APPROVED_INTERNAL`（`training` 范围）；`DRAFT`/旧版本不可读；
3. **带引用问答**：`/v1/training/ask` 已实现但返回 501 —— 需要接 AnswerService（同一条闸门，
   含 `literal_support`）；引用必须可点开证据；
4. **测验**：提交 attempt → 判分；错题进坏例集；
5. **导师签核**：`practical-signoffs` → **AI 不得自动授予上岗资格**（Rev2 §1.1-6）；
6. **审计**：分配/阅读/问答/测验/签核全部可在审计表追溯；
7. **联动**：撤销某课程后，学员端立即不可读（同 P0 同类三路：检索/问答/证据）；
   历史版本（`SUPERSEDED`）只允许追溯审计，不作为回答依据。

### B. 经验采集链路（Rev2 §3.3，受 ADR-05 约束）

1. **录音授权**：上传前必须记录授权（谁、何时、范围、保留期）——ADR-05 未签前，
   只做"授权台账 + 拒绝上传"的最小实现，不做真实 ASR 接线；
2. **私有转写**：转写落库标记 `owner_experience` + `RAW`，**任何检索路径都不可见**；
3. **带时间戳草稿**：由转写生成 `claim/条件/例外/风险/证据位置/待确认` 草稿（人工可改）；
4. **人工审核** → 技术审批 → 独立公开审批（如对外）；
5. **受控发布**：只有审批后的版本进入索引；原始录音与全文转写永不对外检索。

### C. 外贸客服独立端到端（Rev2 §1.1-4/5，受 ADR-07 约束）

1. 独立客户令牌（`allowed_scopes={customer_public}`）与独立审计维度；
2. 只回答批准公开的产品事实；**价格/交期/质量承诺/定制/MOQ 一律 `HUMAN_REVIEW_REQUIRED`**；
3. 拒绝码与内部问答一致（`NO_EVIDENCE` / `ACCESS_DENIED` / `HUMAN_REVIEW_REQUIRED`）；
4. 只读、不接线自动发送（ADR-07 未签）；测试断言问答不产生 outbox 事件。

### D. 索引发布与撤销（工程闸门）

1. 发布：`index_generation` 递增后才对新版本可检索；旧 generation 不影响在线查询；
2. 撤销：状态一变，检索/问答/证据**立即**不可见（不依赖物理删除）；
3. 重建收敛：断点重建后，可见集合与状态一致（有对账脚本）。

### E. 固定金标准回归 + RAG Triad（质量闸门）

1. 金标准集固定为独立文件（不含客户价格本体），hash 入证据；
2. Triad 三项（上下文相关性 / 有据性 / 答案相关性）用脚本化 + 真实模型两层：
   - 脚本层进 CI（`tests/e2e/test_answer_gate_golden.py` 已有 8 条）；
   - 真实模型层走 `answer_regression`，门禁阈值待 ADR-08 校准。
