# ADR 台账（Phase 0）

本目录是架构决策的**唯一登记处**。`UNSIGNED` 表示业务方未确认，代码不得把默认建议当作已批准。

登记规则：

1. 每个 ADR 必须写明"未签署时代码的实际行为"，让未决策项在运行时表现为不可用或显式报错，而不是悄悄走默认值；
2. 签署需要记录决策人、日期、选择项与理由；文件内 `status` 字段同步更新；
3. 修改已签署 ADR 等于新决策，需新增编号或标注 superseded，不得直接改写历史。
